# Personal Introduction Card

A simple, responsive, and interactive personal introduction card built using **HTML, CSS, and JavaScript**. It provides a creative way to introduce yourself, share a professional message, and connect with others.

## Overview

The Personal Introduction Card is designed for professional communication, networking, business introductions, and marketing outreach.

Instead of sending a traditional introduction message, users can share a personalized webpage containing their introduction, profile photograph, social links, and a dedicated message popup.

## Features

- **Personal Introduction:** Display your name and a short introduction.
- **Profile Image:** Showcase your photograph.
- **Interactive Message:** Open a personalized message in a popup.
- **Social Media Links:** Connect through Instagram, LinkedIn, and Portfolio.
- **Responsive Design:** Optimized for desktop, tablet, and mobile screens.
- **Simple Interactions:** Close the message using the close button, outside click, or Escape key.
- **Clean UI:** Minimal design with a light background and professional styling.

## Technologies Used

- HTML5 – Page structure and semantic sections.
- CSS3 – Styling, layout, and responsive design.
- JavaScript – Popup functionality and user interactions.
- Bootstrap 5 – Bootstrap CSS framework integration.

## Getting Started

Follow these steps to run the project locally.

### 1. Clone the Repository

```bash
git clone https://github.com/Rakhee1308/Personal-Introduction-Card.git
```

### 2. Navigate to the Project Directory

```bash
cd Personal-Introduction-Card
```

### 3. Run the Project

Open `index.html` in your browser.

You can also use the Live Server extension in VS Code for a better development experience.

## Customization

You can personalize the card by modifying:

- **Name and Introduction:** Update the content in `index.html`.
- **Profile Image:** Replace `images/profile.jpg` with your photograph.
- **Social Links:** Add your actual social media and portfolio URLs.
- **Message:** Customize the professional message displayed in the popup.
- **Colors and Layout:** Modify `style.css` to change the appearance.
